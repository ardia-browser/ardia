## Fixed

- **The developer bar no longer appears while you browse.** In 0.2.47-nightly.8 the striped bar for local sites showed
  up during ordinary navigation. It is gone from the app, along with the Developer Mode row in Site Controls. It will
  return as a plugin you turn on yourself.
- **Importing from Arc and other Chromium browsers brings over your default search engine.** Thanks,
  [@Neel2107](https://github.com/ardia-browser/ardia/pull/1795).
