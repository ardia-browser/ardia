## New

- **Ardia runs on Linux.** The same sidebar, tabs, Peek, picture in picture, Little Ardia and split view, on
  Chromium 157 with Helium's patches, for x86-64 on Wayland or X11. Download the tarball and run its `install.sh`, or
  start it from the unpacked folder.
- **Ardia runs on Windows.** An installer for Intel and AMD PCs and one for Arm PCs installs Ardia for your user only,
  with no admin prompt. It isn't signed yet, so Windows asks first: choose More info, then Run anyway. From this
  build on, Ardia for Windows offers each new release itself.

## Fixed

- **A new Linux window no longer flashes Chromium's own toolbar.** For about half a second a new window showed a dark
  frame and then Chromium's "Search DuckDuckGo or type a URL" bar before Ardia drew. It now stays plain until Ardia's
  first frame is ready.
