## New

- **Ardia's own interface can be bigger or smaller.** Settings › Appearance › Interface Size scales the sidebar,
  toolbar, menus and Settings from 80% to 150% in 5% steps, as soon as you pick one. Web pages keep their size. On the
  Mac only for now.
- **Tabs on top stay usable with many tabs.** Tabs shrink to their icon before the strip scrolls, the selected tab keeps
  room for its title, and a tab that shares its icon with another keeps a title so you can tell them apart. Tabs fade
  at an edge that hides more, and dragging a tab to that edge scrolls the strip.

## Fixed

- **The Mac gets what 0.2.47-nightly.3 left behind.** That nightly reached Linux and Windows only. This one carries the
  Mac's share: Space and the arrow keys reach the page again after the command bar closes or you switch tabs with it
  open, Clear Browsing Data stays open with an error and Retry when clearing fails, and a tab group without an icon
  shows a folder. Thanks, [@Bil0000](https://github.com/ardia-browser/ardia/pull/1894),
  [@mjkang-estrella](https://github.com/ardia-browser/ardia/pull/1937) and
  [@mtbaqer](https://github.com/ardia-browser/ardia/pull/376).
