## New

- **The ardia command is now a plugin.** Command Line appears under Settings › Plugins; installing it puts `ardia` on
  your PATH, and once installed it stays, with no switch. If you already had the command and let it control Ardia, it
  carries over by itself. If you had turned control off, it stays off until you install Command Line there.

## Fixed

- **Tabs, folders and tiles no longer squish and bounce when pressed.** The effect arrived in 0.2.47-nightly.6 and made
  a folder's icon slide and spring back. They hold still again; the hover highlight still fades out.
- **Folders look the way they did in 0.2.47-nightly.5.** A group with no colour of its own gets its tinted folder back,
  and a live folder shows the folder again, not its service's icon.
- **The window buttons no longer sit over the page while the auto-hidden sidebar is away.** They come and go with the
  sidebar, on the left, on the right and with tabs on top.
- **Little Ardia hides the profile button when the sidebar's switcher is set to Nothing**, as the main window does.
  Switching profile stays in the Profiles menu and on ⌃1 to ⌃9.
- **Sync no longer stops on a profile that holds back many items at once.**

## Smaller

- Video upscaling now sharpens only videos of 720p and below.
- The content blocker is uBlock Origin 1.76.4.
- The reload button stays still when clicked, and tab previews and toasts fade in place.
- Peek's side buttons centre their glyphs and line up with the title row. Thanks, [@remixtedi](https://github.com/ardia-browser/ardia/pull/2684).
