# Ardia Glossary

The words Ardia uses for its own concepts. One term per concept; the ones under _Avoid_ mean the same thing and are not used.

## Autofill

**Apple Passwords**:
The logins, passwords and verification codes the user keeps in Apple's Passwords app, synced across their Apple devices.
_Avoid_: iCloud Keychain, Keychain, iCloud Passwords

**Password manager**:
The one place a profile fills logins from and saves new logins to: Ardia, Apple Passwords, a password-manager plugin, or None.
_Avoid_: password source, provider, vault

**Pairing**:
Linking Ardia to Apple Passwords by typing the six-digit code the Passwords app shows. It lasts until the Mac ends Apple's side of the link.
_Avoid_: connecting, signing in, unlocking

**Login list**:
The list under a sign-in field that offers the current site's saved logins, in either engine.
_Avoid_: dropdown, suggestions, autofill menu

**Verification code**:
A six-digit sign-in code the Passwords app generates for a site, offered in the Login list on a code field.
_Avoid_: TOTP, 2FA code, OTP

**Me card**:
The user's own card in macOS Contacts, the one marked as them. Its name, email, phone and addresses can fill forms.
_Avoid_: my contact, contact card, profile
