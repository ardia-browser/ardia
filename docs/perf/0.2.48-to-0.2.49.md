# 0.2.48 → 0.2.49 release gate

0.2.49 moves the engine from Chromium 158.0.8127.36 (Helium 0.22.1) to 158.0.8127.88 (Helium 0.22.4) on the Mac, Linux and Windows, and collects the 0.2.49 nightlies. The candidate is CI's signed and notarized dry run of 82a399cbd (build 141, run 45916607214). It is published from 2763e843e, which differs from it only by test files, the Windows engine pin and iPhone code. The control is the published 0.2.48. 0.2.48 is native API 91 and 0.2.49 is 99, so the control ran its own bench bundle, built from `v0.2.48` (`dist/0.2.48/bench/main.jsbundle`). Measured on mbp2 on 2026-11-26, interleaved, on AC, holding the perflab lock, run from Terminal in the GUI session.

**Result: two idle wakeup rows fail by hairs, accepted by the owner.** The first run doesn't count: another session's Rust build and a GPUI test window ran on mbp2 during it, and round 1 ran at a load average of 75 to 121. It failed new tab first paint and first frame, tab switch and idle wakeups at 20 tabs. The full rerun on a quiet mbp2 (load average 6 to 10, nothing else building, logged every 30 s) passes all four and fails two others:

- idle wakeups at 1 tab, all processes: 5.78 → 5.84 /s (+0.07, +1.2 %), worse in both rounds by more than 0.2.48's 0.02 round spread;
- idle wakeups at 20 tabs, browser process: 2.83 → 2.94 /s (+0.11, +4 %), worse in both rounds by more than 0.2.48's 0.04 round spread.

Split by process over all four rounds, the 1-tab increase is in the renderers in every round (+0.03 to +0.13 /s), where no app code runs, so it's the engine update. The 20-tab browser-process increase showed in 3 of 4 rounds (−0.08, +0.09, +0.04, +0.13 /s), about one wakeup every 10 s, too small for a nightly bisect to place (the 0.2.47 follow-up found the same for a larger effect). The owner accepted both and the release shipped.

Launch is faster on the quiet run: window shown 619 → 489 ms, first frame 728 → 565 ms (pooled medians), inside 0.2.48's own wide round spread, so not claimed as a win. Memory is the same at every tab count.

To watch in 0.2.50: idle wakeups at 20 tabs in the browser process, and `perf_launch` on the dashboard for the launch numbers.

## Other gates

- Smoke and update test against 0.2.48: 79 pass, 0 fail, 5 skipped. Terminal on mbp2 lacks Accessibility and Screen Recording, so the three passkey dialog checks and ⌘1/⌘2/⌘9 didn't run, and 0.2.48 bundles no Command Line, so that check is N/A. Those are unverified for this release.
- Ratchet: ok, 0 over, 114 below their ceiling, after the fixes in f638a95c3, eace2153a, 60a0bc1da and b9c868679.
