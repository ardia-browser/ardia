## New

- **Ardia runs on Linux.** The same sidebar, tabs, Peek, picture in picture, Little Ardia and split view, on
  Chromium 157 with Helium's patches, for x86-64 on Wayland or X11. Download the tarball and run its `install.sh`, or
  start it from the unpacked folder. Thanks, [@mckamyk](https://github.com/ardia-browser/ardia/pull/622),
  [@HarshitRuwali](https://github.com/ardia-browser/ardia/pull/1869) and
  [@Neel2107](https://github.com/ardia-browser/ardia/pull/1785).
- **Linux has most of the Mac's extras.** Profiles, sync of passwords, the `ardia` command with userscripts, config
  and themes, screen sharing, links from other apps, default browser, open at login, notifications, Share and the
  first-launch meadow.
- **Ardia runs on Windows.** An installer for Intel and AMD PCs and one for Arm PCs installs Ardia for your user only,
  with no admin prompt. It isn't signed yet, so Windows asks first: choose More info, then Run anyway. From this
  build on, Ardia for Windows offers each new release itself.
- **Windows looks and works like a Windows app.** Mica behind the window, real blur, title bars and window buttons
  that follow light or dark, Windows' own snapping when you drag a window, and a menu button beside minimize with
  Settings and Check for Updates. Peek, Split View, full screen, Ctrl+Z to reopen a closed tab, dropped files and
  links, and real notifications all work.
- **Windows brings your other browsers with it.** Import reads Chrome-family browsers, Arc and Zen spaces, and
  Firefox and Zen passwords and cookies. Ardia can be the default browser, open links in other apps, export bookmarks
  and passwords, load unpacked extensions, and sync with your Mac through any folder, OneDrive included. Passwords
  don't sync on Windows yet.

## Fixed

- **A new Linux window no longer flashes Chromium's own toolbar.** For about half a second a new window showed a dark
  frame and then Chromium's "Search DuckDuckGo or type a URL" bar before Ardia drew. It now stays plain until Ardia's
  first frame is ready.

## Smaller

- The rest of this build reached the Mac in 0.2.47-nightly.4, and its notes list every change.
